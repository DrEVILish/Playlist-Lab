Lidarr

A second missing-track acquisition path alongside Deemix. Finds (or adds and monitors) a track's artist in Lidarr and triggers a search across Lidarr's own configured indexers - Lidarr's indexers and download client still need to be set up in Lidarr itself.

YouTube

Google OAuth credentials used for the "YouTube" cross-import target (playlists created on a user's YouTube account) and for matching against YouTube-hosted tracks. Create an OAuth client under APIs & Services → Credentials in Google Cloud Console, enabling the YouTube Data API v3, and add the redirect URI below to it as an authorized redirect URI.
