Reverse Proxy Setup

If you're running Playlist Lab behind a reverse proxy (Nginx, Apache, Caddy, etc.):

  1. Set TRUST_PROXY=true in your .env file
  2. Configure your reverse proxy to forward the Host and X-Forwarded-Proto headers
  3. Update OAuth app redirect URIs to match your public URL
  4. Restart the server

Login and OAuth callback URLs are built from the request itself (scheme + host), not a fixed configured domain - so this works automatically for whatever hostname a visitor actually used, including a LAN IP alongside a public domain.
